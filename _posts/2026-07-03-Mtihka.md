# Mithka — 轻量级 Telegram 客户端

## Meet Mithka

灵感源自 QQ 紧凑界面的轻量级独立 Telegram 客户端。基于 TDLib 构建，兼顾极致速度与稳定性。


## 卓越性能

### 直接连接 Telegram 云服务

Mithka 在您的设备上直接运行 Telegram 官方客户端数据库库（TDLib），不通过任何中转服务器处理您的数据。所有通信均直接安全地传输到 Telegram 官方 API。

- 极速响应的会话列表和搜索索引
- 完整支持动态贴纸、GIF 和故事模式
- 自适应的 Cupertino 风格布局（支持 iOS 和 Android）

#### Mithka 客户端 企鹅版本


## 名字背后的故事

Mithka 的名字源于传统的伊斯兰质量单位 **mithqāl**（مثقال），约等于 4.6875 克。

在物理天平上，这比 Telegram 的企鹅吉祥物 pengram（+ gram，读作 penta-gram 即表示 5克/5gram，同时也是五线谱的五根线双关）还要轻一些。正如其名，Mithka 旨在成为羽量级的轻捷存在。


## 为追求极致聊天的极简主义者设计

专注于速度、极简以及视觉敏捷的独立第三方聊天体验。


### 底层基于 TDLib

使用高性能 C++ TDLib 数据库绑定与 Telegram 交互。设备直连网络，无需第三方中介代理。


### 隐私至上的架构

无数据收集后台。我们不会存储或处理您的聊天历史。Sentry 和 Google Analytics 数据均已彻底匿名化。


### Cupertino 原生质感

自适应主题由 iOS 动态资源调校而来。包含自定义 UI 控件、流畅的侧滑以及完全可自定义的主题色。


## 准备好体验 Mithka 了吗？

Mithka 处于活跃的测试阶段。您可以通过 Apple TestFlight 安装 iOS 客户端，或从我们的 GitHub 页面下载 Android APK 安装包。
> 官网：https://mithka.ieb.app/

### iOS：安装 TestFlight

从 App Store 下载 TestFlight 应用，然后点击上方 TestFlight 按钮接受邀请安装 Mithka 测试版。
> https://testflight.apple.com/join/tVC8WkbW

### Android：GitHub Releases

访问 Mithka GitHub Releases 页面，下载最新的 APK 文件并在您的 Android 设备上安装。
> https://github.com/iebb/mithka/releases
